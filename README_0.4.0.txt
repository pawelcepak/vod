VOD USB Android 0.4.0

Automatyczny katalog TVP z głównego adresu serialu.
Aplikacja pobiera metadane, sezony i odcinki z API TVP, zapisuje numer, tytuł, miniaturę i webUrl, cache'uje katalog oraz automatycznie porównuje go z zawartością pendrive.

Domyślny adres:
https://vod.tvp.pl/seriale,18/m-jak-milosc-odcinki,274703

Tryb ręczny numer|URL pozostaje jako awaryjny.
Pobieranie w tle, kolejka, USB i audio0-Polski pozostają bez zmian.
Podpis release jest ten sam co w 0.3.1, więc 0.4.0 powinno zainstalować się jako aktualizacja.
