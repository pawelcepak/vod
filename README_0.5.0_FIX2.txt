VOD USB 0.5.0 fix2
==================

Zmiany UX:
- lista odcinków nie jest pokazywana przed wyborem pendrive,
- po odczytaniu pendrive aplikacja automatycznie ustala następny numer:
  najwyższy odcinek na USB + 1,
- ręczny numer startowy przeniesiony do Ustawień zaawansowanych,
- domyślnie widoczne 10 kolejnych odcinków,
- przycisk "Pokaż następne" dodaje kolejne 10,
- techniczny brak informacji o wolnym miejscu jest ukrywany,
- "Odśwież" jest mniejszym przyciskiem pomocniczym,
- blok postępu, pusty progressbar, kolejka i "Zatrzymaj" są ukryte,
  gdy nic się nie pobiera,
- sekcja zaawansowana pozostaje schowana,
- lista odcinków na USB i przycisk odtwarzania pozostają w prostym układzie.
